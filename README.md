# Sweet N Soft Showcase

Create a modern, premium, elegant, and highly interactive bakery website for a bakery brand called "Sweet N Soft."

The website should feel warm, cozy, luxurious, and delicious. Use soft pastel colors with beautiful animations and premium UI inspired by modern food brands.

The website must be fully responsive and optimized for desktop, tablet, and mobile.

DESIGN GOAL

--------------------------------

The website should feel like a premium international bakery brand, similar to luxury dessert shops. Every section should include modern UI, beautiful gradients, elegant typography, smooth animations, high-quality bakery photography, and polished interactions. Prioritize visual storytelling, conversion-focused design, and an inviting experience that encourages visitors to browse products and place orders.

Generate production-ready code with reusable components, clean folder structure, optimized performance, SEO best practices, and placeholder content/images that can easily be replaced later.
